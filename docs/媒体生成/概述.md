# 媒体生成（dsh-toonflow-media）

> 源码：`plugins/dsh-toonflow-media/` · [插件 README](../../plugins/dsh-toonflow-media/README.md) · [文档索引](../索引.md)

## 功能

不启动 Toonflow 服务器，在 DSH 进程内解析 BeefTV 渠道 manifest 并直接调用上游 API 生成图片 / 视频 / 音频；渠道清单在 `manifests/*.json`。

## 安装

```bash
dsh plugin --profile web add dsh-toonflow-media
```

安装后**需重启宿主**才能挂载 bundle patch（patch 含配置行/表达式，热挂载只支持纯 insert）——不重启则插件不挂载、工具不注册。

## 使用

- `toonflow_media_set_key` — 写入渠道 API key（持久化到 `$DSH_HOME/toonflow-media/config.json`，每渠道一次）；
- `toonflow_media_list_models` — 列出可用渠道与能力（image / video / audio）；
- `toonflow_media_generate` — 按 `providerId` + `model` 生成，返回 url / base64 / binary。

## 生成流程

manifest 驱动：create → 轮询 → 取产物；`create.files` 支持 multipart 上传；轮询失败 / 超时 / 中止时调用 manifest 声明的 `cancel` 端点。

## 指针

- 渠道模板解释与生成调用：`plugins/dsh-toonflow-media/src/`；
- 渠道 manifest：`plugins/dsh-toonflow-media/manifests/`。
